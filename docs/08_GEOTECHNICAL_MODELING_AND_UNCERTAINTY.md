# GeoReport3D — Geological Modelling and Uncertainty

## Core rule

Do not interpolate simply because two boreholes exist.

The 3D model should represent what is observed, what is inferred, and what is unknown.

## Evidence classes

```text
OBSERVED
  directly measured / explicitly mapped

INFERRED
  derived from multiple observations or an engineering geological interpretation

HYPOTHESIS
  generated by a modelling assumption under insufficient evidence
```

## Spatial consistency

A candidate geological surface should satisfy available constraints such as:

- borehole interval observations
- mapped contacts
- section contacts
- known faults
- geological ordering
- structural attitude where available
- elevation/topography
- tunnel alignment
- explicit engineering interpretation in the report

## Do not confuse smoothness with correctness

A mathematically smooth surface between BH-01 and BH-02 can be geologically wrong. Smoothness may be an objective or regularizer, but it is not evidence.

## First modelling strategy

For MVP, avoid a complex stochastic engine. Implement a transparent deterministic baseline:

1. Build borehole observations.
2. Build explicitly extracted contacts.
3. Project observations into common coordinates.
4. Create simple section/plane constraints.
5. Fit a surface only where enough constraints exist.
6. Mark unsupported regions as uncertain.

The modelling API should allow later algorithms:

- kriging/co-kriging
- radial basis surfaces
- implicit geological modelling
- level-set methods
- stochastic simulation
- structural constraints

## Uncertainty representation

Keep at least two concepts separate:

### Extraction uncertainty

Did the AI correctly read the source?

### Spatial uncertainty

How uncertain is the location of the inferred geological boundary between observations?

A future model may store:

```json
{
  "uncertainty": {
    "horizontal_m": 8.7,
    "vertical_m": 4.1,
    "method": "pending",
    "support_count": 4
  }
}
```

These numbers must not be fabricated. They should come from an explicit model or remain null.

## Visualisation concept

Use different visual semantics for:

- observed
- inferred
- hypothesis
- unknown/low-support

Never use visual smoothness alone to imply confidence.

## Future research direction

A strong research extension is a **constraint-aware uncertainty field** where uncertainty increases with distance from supporting observations and decreases where independent evidence (e.g. boreholes + sections + mapped contacts) converges.
